# TenantFlow Hub

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Supabase

## Run Locally

1. Install dependencies:

```sh
npm install
```

2. Ensure env file exists at `tenantflow-hub/.env` with:

```env
VITE_SUPABASE_PROJECT_ID=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
VITE_SUPABASE_URL=...
```

3. Start development server:

```sh
npm run dev
```

4. Open the URL shown in terminal (usually `http://localhost:8080`).

## Build

```sh
npm run build
```
